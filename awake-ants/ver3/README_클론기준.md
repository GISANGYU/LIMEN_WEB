## 1. 레퍼런스에서 가져오는 것 / 가져오지 않는 것

**그대로 재현 (원본과 똑같이):**
- 2-1 의 렌더 파이프라인: 노이즈 흐름장 텍스처 → GPGPU 입자 100×100 → 흐름 방향으로 눕힌 짧은 막대 인스턴스 → 잔상(persistence) → 투사면 → 후처리.
- 셰이더 규칙: 흐름 각도 = `turbulence(uv*0.5+translation) * uDetail`, 입자 이동 = `noise.xy * dt * uSpeed * 속도계수`, 수명 감소 후 원위치 재생성, **12개 중 1개는 커서 둘레 고리에서 태어나는 방출 입자**(수명 15배 빠름), 잔상 = `mix(현재*uBrightness, 이전, 1-uFadeStrength)`.
- 2-1 의 **처음 두 컷(0~27.8초)** 카메라·uniform 키프레임과 베지어 곡선. 수치는 `tools/extract_theatre.py` 로 원본 `state.json` 에서 뽑아 `data/sov_ch2_1.json` 에 둔다. 손으로 옮겨 적지 않는다.
- 컷 경계의 `uReset`(잔상·입자 초기화), 3초부터 커서 반응 켜짐, 2초 입력 없으면 리사주 자동 커서(`sin(t*.578)*.65, -cos(t*.523)*.65`).
- 나레이션 구조: **큐 하나 = 소리 + 자막**. 자막은 흐림→선명 3.5초 등장, 이전 자막은 흐려지며 퇴장, 커서가 가까우면 다시 흐려짐. 자막은 화면 오른쪽 정렬(원본 2챕터 `--right`).
- 진행 UI: 시작 화면(제목+들어가기 버튼, 오디오 잠금 해제) → 챕터 카드(작은 머리말·이탤릭 한 줄·큰 제목·조작 안내) → 재생 → 끝 화면. 원형 진행 링, 장면 건너뛰기.
- 후처리 값: Bloom 0.71 / radius 0.89 / threshold 0.28, 색수차, 비네팅 0.994, 그레인 0.19.

**가져오지 않음:**
- 원본 영어 음성(sfx.mp3)·글꼴(Palace/Bellefair)·로고·문장. 코드 번들을 복사하지 않고 같은 규칙으로 새로 짠다.
- 렌즈플레어, 2-2 리본 떼(이번 범위 밖), Theatre.js 런타임(베지어 재생기를 직접 짠다).

- 톤: 다큐멘터리. "~한다" 대신 "~합니다 / ~되죠". 추상적·동화적으로, 스토리보드 v6 개미 의미(1-01 → 1-05)와 AWAKE 질문을 따른다.

- 배경음: `js/music.js` 생성형 앰비언트(D 도리안 패드 + 펜타토닉 벨 + 5초 잔향). 나레이션 중엔 0.55배로 낮춘다. Higgsfield 에는 단독 음악 모델이 없어 파일 없이 만들었다.

## 6. 공개 배포 전 할 일

1. 나레이션 문장 팀 확정 → `data/cues.json` 교체, 녹음본 `audio/`.
2. `data/sov_ch2_1.json` 의 레퍼런스 수치를 우리 수치로 다듬기 (지금은 원본 그대로 = 로컬 테스트 전용).
3. AWAKE 안에서 개미가 들어갈 섹션 결정 (웹팀).
4. 그 뒤에 `LIMEN_WEB` 사본으로 복사·배포 ([[limen-web-pages-deploy]] 절차).
